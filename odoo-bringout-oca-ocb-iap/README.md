# In-App Purchases


This module provides standard tools (account model, context manager and helpers)
to support In-App purchases inside Odoo. 

## Installation

```bash
pip install odoo-bringout-oca-ocb-iap
```

## Dependencies

- web
- base_setup

## Source

- Repository: https://github.com/OCA/OCB
- Branch: 18.0
- Path: addons/iap
